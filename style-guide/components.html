09 · Miscelánea

Custom Cursor .cursor

Círculo de 8px blanco con mix-blend-mode: difference. Se expande a 40px sobre enlaces y botones. Solo en dispositivos con pointer fine.

Representación visual
Default (8px)
Hover/Expand (40px)

Scroll Reveal .reveal

Elementos entran con translateY(28px) + opacity 0 y se hacen visibles al cruzar el viewport (threshold 0.1). Delays incrementales con .reveal-delay-1 a .reveal-delay-4 (100ms cada uno).

Propiedades de animación
Propiedad transform opacity duration easing threshold
Valor translateY(28px) → 0 0 → 1 1s cubic-bezier(0.25, 0.1, 0.25, 1) 0.1 / rootMargin: -40px

Layout container max-width: 1360px

Todos los contenedores principales usan max-width 1360px con margin auto. Padding horizontal fluid con clamp(24px, 5.5vw, 96px).
